# Tsuki Dashboard

The legacy staff dashboard for **Tsuki**, a K-pop card-collection Discord bot currently used in 2,500+ servers by 4,500+ users.

This dashboard gave staff a central interface to manage the bot's content and events, replacing the more manual Discord-based workflow.

## What staff could do

- Upload, edit and remove collectible cards
- Create and manage events
- Organize content without relying on Discord commands
- Maintain the collection system through a dedicated web interface

## Status

This repository contains the original Tsuki dashboard. Its functionality was later moved into KōdoBot.
